💹 Финансовый отчёт

P&L по месяцам. Выручка — «до СПП» (деньги на р/с), проценты считаются от неё. Клик по жирной строке — раскрыть категории.
Загрузка…
Самовыкупы / блогеры / инструменты менеджера — ручной ввод в таблицу manual_expenses (marketplace, month, category: самовыкупы|блогеры|инструменты, amount). Пока не заполнено — строки показывают 0. Разбивка по категориям для них не считается (нет source-данных по категориям).
Выручка после СПП — из файла «Заказы» (OZON убрал это поле из API 12.11.2025), сопоставляется по номеру отправления. Покрытие частичное — см. «сопоставлено» под строкой; разбивки по категориям для СПП нет.
«Прибыль МП» и «ЧП» пока совпадают: постоянные расходы и налог/УСН сознательно не включены в отчёт (нет источника данных) — как только появятся, ЧП станет отдельной строкой ниже.
Классификация по выручке: сортировка по убыванию, накопительный % — A ≤80%, B ≤95%, C ≤100%.
Выбери период и нажми «Построить»
Цветомодель — артикул без размера (всё до последнего «/»). Выручка/себестоимость/комиссия/логистика — фактические данные за выбранный период (не месячный агрегат).
